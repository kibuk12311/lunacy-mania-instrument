# Обученный генератор: как он угадывает карты мапперов

Обучено на 6326 картах 4K рис из папки osu!\Songs (14,264,866 точек сетки 1/4). Проверка — на 15% сетов, которых модель не видела.

| Что | Модель | Старый способ (сила удара) |
|---|---|---|
| Где поставить ноту, AUC (1 = идеально, 0.5 = наугад) | 0.881 | 0.559 |
| Где поставить ноту, точность-полнота (AP) | 0.942 | 0.750 |
| Сколько нот в строке, точность | 69.3% | 47.3% (всегда самый частый размер) |
| Плотность по частям песни совпадает с маппером (корреляция) | 0.71 | — |

## Проверка целиком: 12 песен, которых модель не видела

Для каждой песни берётся настоящая карта человека (дан по нашему анализатору), и генератор делает карту того же дана на том же тайминге.

| | Старый генератор (правила) | Обученный генератор |
|---|---|---|
| Попал в заказанный дан | 7 из 12 | **12 из 12** |
| Ноты там же, где у маппера (F1, ±20 мс) | 0.783 | **0.815** |
| Плотность по частям песни совпадает с маппером (корреляция по 8 битам) | 0.641 | **0.662** |

Как пересобрать модель (на компьютере с osu! и видеокартой NVIDIA):

```
node tools/build-mapper-dataset.mjs "A:/Games/osu!/Songs" data/mapper 12
.venv/Scripts/python -I tools/train_mapper.py data/mapper models/mapper.json reports/mapper.md
```
